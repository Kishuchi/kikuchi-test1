# 非機能要件書

## 1. 概要

本ドキュメントは、Web電卓アプリケーションの非機能要件を定義する。

## 2. 対応環境

### 2.1 対応ブラウザ

| ブラウザ | バージョン | 対応状況 |
|----------|------------|----------|
| Microsoft Edge | 最新版 | ○ 対応 |
| その他のブラウザ | - | × 非対応 |

### 2.2 対応デバイス

| デバイス種別 | 対応状況 | 備考 |
|--------------|----------|------|
| モバイル（スマートフォン） | ○ 対応 | 主要な利用環境として想定 |
| タブレット | ○ 対応 | モバイル対応に含む |
| デスクトップ | ○ 対応 | - |

### 2.3 レスポンシブデザイン

- モバイル利用を想定したレスポンシブデザインを採用
- タッチ操作に最適化したUI設計

## 3. セキュリティ要件

### 3.1 認証・認可

| 項目 | 要件 |
|------|------|
| ユーザー認証 | 不要 |
| 認可制御 | 不要 |

**理由**: 本アプリケーションはデモ目的であり、認証・認可機能は不要。

### 3.2 セキュリティ準拠要件

| 項目 | 要件 |
|------|------|
| セキュリティ規格準拠 | なし |
| 個人情報保護 | 対象外（個人情報を扱わない） |

**理由**: 本アプリケーションはデモ目的であり、特定のセキュリティ規格への準拠は求めない。

## 4. インフラストラクチャ

### 4.1 ホスティング

| 項目 | 要件 |
|------|------|
| カスタムドメイン | 不要 |
| SSL/TLS | 標準提供されるものを使用 |

### 4.2 CI/CD

| 項目 | 要件 |
|------|------|
| CI/CDツール | GitHub Actions |
| 自動デプロイ | 対応 |
| 自動テスト | 対応 |

## 5. テスト要件

### 5.1 テスト種別

| テスト種別 | 実施有無 | ツール |
|------------|----------|--------|
| 単体テスト | × 非実施 | - |
| 結合テスト | × 非実施 | - |
| E2Eテスト | ○ 実施 | Playwright |

### 5.2 E2Eテスト方針

- Playwrightを使用したEnd-to-Endテストを実施
- 主要な計算機能の動作確認
- エラー処理の確認
- キーボード入力の確認

## 6. パフォーマンス要件

### 6.1 要件定義

| 項目 | 要件 |
|------|------|
| 応答時間 | 規定なし |
| 同時接続数 | 規定なし |
| 可用性 | 規定なし |

**理由**: 本アプリケーションはデモ目的であり、パフォーマンス要件は設けない。デモ用途のため、実運用レベルのパフォーマンス保証は不要である。

### 6.2 補足事項

- デモ目的のアプリケーションであるため、本番環境相当のパフォーマンス最適化は対象外とする
- 将来的に本番利用を想定する場合は、別途パフォーマンス要件を定義すること

## 7. 運用・保守要件

### 7.1 ログ管理

| 項目 | 要件 |
|------|------|
| アプリケーションログ | 規定なし |
| アクセスログ | 規定なし |

### 7.2 監視

| 項目 | 要件 |
|------|------|
| 死活監視 | 規定なし |
| エラー監視 | 規定なし |

**理由**: デモ目的のアプリケーションであり、運用・保守に関する要件は設けない。
